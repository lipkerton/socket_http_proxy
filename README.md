# Что это? #
Это я пытаюсь сделать прокси на сокете.
Реализовано:
- Создание серверного сокета.
- Создание клиентского сокета (для тестирования).
- Асинхронное чтение сообщений от нескольких клиентских соединений.

# Особенности #
- Использованы модули `select`, `socket`, `sys`, `logging`, `threading`, `ipaddress`.
- Настроено логгирование.
- Сделаны декораторы и валидаторы.
- IP-адрес и порт сервера могут быть введены через командную строку.

# Проблемы #
- Функция `recv()` является блокирующей - это не позволяет асинхронно считывать запросы пользователей (я так думаю).
- Если убрать блокировку, то программа выкидывает ошибку `BlockingIOError`; ошибка возникает потому, что `recv()` перестает ждать данные и, когда ничего не видит на входе, паникует.
- Чтобы убрать это поведение нужно проверять соединение на наличие данных - это делает функция `select()` из модуля `select`.
- Т.к. эта функция ожидает данные на протяжении 0.1 (раньше было так - сейчас я выставил половину секунды), то в логах можно увидеть бесконечное количество сообщений о том, что данные получены не были.

# Как запустить? #
Чтобы запустить нужно клонировать репозиторий и ввести команды:
```Bash
python main.py <IP-сервера> <порт>
```
Ради шутки можно отправлять сообщения от скрипта клиента - он находится в папке `method`:
```Bash
python sock_client.py
```
Но будьте бдительны - я настраивал его только на подключение к локальному адресу.
